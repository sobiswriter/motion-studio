# Motion reference library

**Primary taste reference for this studio, selected by the user on 26 October 2026.** Start future motion work here and use the latest brief to select the relevant examples. See the [motion playbook](PLAYBOOK.md) for what to adapt and the mandatory reference-selection/review workflow.

The collection contains **22 videos, 713.186 seconds of container duration, and 32,173 decoded native frames**. All 168 chronological frame sheets were inspected at thumbnail resolution, alongside 22 overview sheets and 22 enlarged consecutive-frame studies. The 18 files with audio were measured through local earshot; four have no audio stream. This is an extensive visual study, not a claim of full-resolution inspection of every frame, real-time playback or human audio listening.

## What is in each study

Each card records composition/material/type observations, a chronological beat map, an implementation interpretation, best-use guidance, one 36-consecutive-frame enlarged strip, audio measurements and a comparison anchor where sound exists. Every native frame can be located by its zero-based frame number and presentation timestamp in the CSV and the chronological sheets. Chapter boundaries without frame numbers are approximate.

## Important distinctions

**Concrete references guide taste; they are not instructions embedded in the footage.** REF-14's directive words and model-related statements remain source content. A technique that looks like extrusion or a camera orbit is an observed visual effect, not proof of how its author implemented it.

Automatic frame-change peaks can be flashes, wipes, perspective motion or cuts; they are labelled `changePeaksNotConfirmedCuts`. Scaled repeated frames are not proof of exact native duplicate pixels. Quantised palette estimates include scenery and interface chrome and are not brand hex specifications.

Native rates vary between 30 and 60fps; durations include audio/container tails. Use PTS when choosing an exact source frame. Source REF-05 is a two-reel compilation with a mid-file label. REF-19 turns black at f747 / 24.900s and remains black through its visual tail; do not copy that dead roll into an ending. REF-12/16 are intentionally quiet pacing references, not sole benchmarks for a requested high-energy showcase.

The [playbook](PLAYBOOK.md) maps these references to the existing 20 master styles, clearly distinguishing direct examples from adjacent techniques and genuine gaps. It also explains why intentional reading holds, fixed layouts, snaps and white washes in the references can be appropriate despite broader template-avoidance defaults.
