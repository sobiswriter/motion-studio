## Commands

Run from motion-studio:

```sh
npm ci
npm run dev
npm run lint
npm test
npm run check:ivans-production
npm run ivans:stills
npm run ivans:draft
npm run ivans:final
```

For one changed event, use `npm run compile:tools`, then `node .cache/scripts/render-ivans.js --frames=495,509,539`. Stills stay reduced. Avoid repeating full-resolution exports.

`ivans:draft` renders the full-film and pilot at half scale. `ivans:final` renders the complete1080p film once. To derive reduced review files from that same master and verify all outputs, run `node .cache/scripts/check-ivans-video.js --derive-previews` after compiling tools. This uses Remotion's bundled FFmpeg/FFprobe; no additional dependency or engine is installed.

## Review limits

All required active media is present; no missing-art placeholder is used. Source paintings are lower resolution than their processed overscan canvases, so1080p output includes upsampling. Generated poses are a consistent working model, not human-approved final character art. Exact vocal phrase timestamps were not independently verified; the cut uses supplied section windows and measured audio rises. These are artistic-review limits, not hidden technical pass claims.
