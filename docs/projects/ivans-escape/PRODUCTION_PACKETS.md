## Dependency graph

ENV01 supplies the opening and one collapsing plane. ENV02 supplies routine, duplicate, warnings, pavement and memory. ENV03 supplies reflection, portrait backing and memory. ENV04 supplies exposed structure, fracture planes, collapse and seam halves. ENV05 supplies boundary, refusal, grid fragmentation and duplicate field. ENV06 is shared by the first pale reveal, the exit and final quiet shot.

CH01/CH02 source files are shared by routine and replacement. CH03 is shared by the approach, refusal, fragment scenes, duplicate field, exit and outside; its alpha creates the outline. CH05 is used twice in SH11 and reused in memory. Reflection front/turn views derive from the canonical identity, while duplicate shots reference the very same image files rather than regenerating people.

All packet changes must preserve the 19 principal shot starts and global 1800-frame runtime. The pilot is a slice of the same data, not a separately edited film.
