# Music reference library

**25 complete tracks · 61:12 total · analysed 28 October 2026.** Originals keep their names and hashes. [Open the audition guide](index.html) for one-player previews, timed candidate ranges and an energy map; [method and selection rules](PLAYBOOK.md). Each study links the original MP3 and the measured evidence.

This is a full-track **objective analysis and editorial selection guide**. Use-case suggestions combine measured shape/spectrum, existing project history and explicit title context. They are not genre, instrument, emotional-tone or vocal detections. Semantic models are unavailable; no human listening is claimed. Only Ivan Is Loading has confirmed vocals, based on user-provided notes.

## Three useful discoveries

- **The Weight of Stillness** has the largest loudness range (**18.3LU**), the widest measured image (**−2.9dB side/mid**) and highest integrated source level (**−10.5LUFS**). Its name is a poor reason to choose it for flat background.
- **Slow Unraveling** has the smallest range (**4.3LU**); **The Slowest Orbit** has the lowest brightness (**416Hz**) and source level (**−14.6LUFS**). Start these auditions when you want restraint, subject to vocal checks.
- **Apex Horizon, Glass and Alloy, Ivan Is Loading, Tactile Precision and The Golden Hour Rise** are shorter than two minutes. A two-minute film cannot use one unchanged as its full bed.

## Using the guide

1. Pick the project behaviour, then compare two or three candidates using the local player’s approximately −18LUFS level-matched preview. Matching loudness reduces louder-is-better bias; a chosen window may still differ from the full-track average.
2. Jump to the rise/steady/dense/long passages. Use the full-track graph and original waveform/spectrum to inspect how those windows relate.
3. Confirm instruments, emotional direction, vocals, phrases and ending by listening. Never certify a beat grid from autocorrelation alone. Preserve the known Ivan exclusion unless the new brief explicitly wants vocals.
4. Record track ID, SHA, exact source in/out, transitions/fades and final mix measurements in each project. Keep effects separate and mix music once.

Local player: open index.html in a browser, or from the repo run a localhost-only static server and visit /docs/music-library/. Source audio stays local; no upload or new model download was performed. Reports contain only metadata/metrics and small images, not duplicated full audio.
