# Primary motion design references

These 22 user-selected videos are the studio's primary taste references. Each filename begins with a stable `REF-xx` ID followed by its content and motion technique.

Open the [searchable library](../../docs/reference-library/README.md) for descriptions, best-use routing, frame studies and audio measurements. Read the [motion playbook](../../docs/reference-library/PLAYBOOK.md) before designing a related production.

[catalog.json](catalog.json) preserves current paths, original names, tags and source hashes. The [rename manifest](../../docs/reference-library/RENAMES.json) maps all original names to the new filenames. Media bytes are unchanged. These files are study references; no production reuse rights have been established.
