# Storylines

Chosen: **One idea. Twenty ways to move.** A single form changes material and motion language through all 20 styles, ending as the Motion Studio signature. The six-beat phrases keep the reel moving as one film.

Alternatives: **The impossible machine** — twenty connected mechanisms assemble a studio mark. **The type specimen** — one typographic sentence is reinterpreted twenty times.

The user approved studio defaults and autonomous completion; the chosen concept combines a material journey with readable typography.
